## Overview / 详细介绍

**English**  
Sylvanisle's Gun Workshop is a Minecraft firearm mod that aims to let players build weapons from various components instead of relying on fixed recipes for finished guns. Assembly follows a set of assembly rules, and different components affect both the appearance and performance of the firearm. Some gameplay elements are also intended to stay closer to the vanilla style.
The current plan is to implement firearms and the core assembly system first, with attachment assembly, ammunition assembly, and blueprints planned for later. I dislike low-quality, janky results — you could call it a perfectionist streak — and this is my first attempt at Minecraft mod development. Given my personal time and energy constraints, I cannot guarantee a fast development pace; actual progress may be slower than expected. But please believe me: if I am able to finish it, it will be a high-quality mod.

**中文**  
森屿的枪械工作室是一个Minecraft枪械模组，目标是让玩家可以用各种组件自行拼装武器，而不是依赖固定成品配方。枪械拼装需要满足一定的装配逻辑，不同组件会影响枪械的外观和性能，且部分玩法会倾向于贴合原版设定。
当前计划先实现枪械和核心拼装系统，后续有配件拼装、弹药拼装和图纸等规划。由于我讨厌劣质感（可以认为有些强迫症），并且这是我第一次尝试Minecraft模组开发，考虑到个人精力问题，我无法保证开发速度，实际开发速度可能比预期更慢。但请相信我，如果我有能力将它做完，它一定会是一个优质模组。
