# Guncraft 枪的世界
A firearms mod for Minecraft Java Edition that is highly faithful to vanilla gameplay and highly customizable.
一个为MCJE设计的高度贴合原版玩法、高自定义程度的枪械模组。

Inspired by a small Minecraft-like Android game from over a decade ago, whose Chinese title is “枪的世界” (“Gun World”).
灵感来源于十几年前有一个Android平台的模仿Minecraft的小游戏“枪的世界”。
